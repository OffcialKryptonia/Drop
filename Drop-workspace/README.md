# Drop — Ride-hailing platform

Monorepo for Drop backend/admin, Drop-rider (customer app), and Drop-driver (driver app).

## Source layout
- `backend-admin/` — original Laravel backend and admin dashboard (legacy project name: texiapp_backend).
- `apps/drop-rider/` — Flutter customer app (legacy project name: texibooking_flutter).
- `apps/drop-driver/` — Flutter driver app (legacy project name: taki_booking_driver).

This is an initial source import. Rebranding, configuration cleanup, security review, and build verification are pending.
